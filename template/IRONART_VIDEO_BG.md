# IronArt — готов монтаж

26 секунди, 30 кадъра/сек. Два самостоятелни монтажа:
- `IronArtLandscape`: 1920 × 1080.
- `IronArtPortrait`: 1080 × 1920.

## Генериране
Необходим е FFmpeg в PATH. От папката `template`:
```sh
npm ci
npm run render:both
```
Резултати: `out/IronArt_16x9.mp4` и `out/IronArt_Reels.mp4`.
Оригиналната демонстрация остава достъпна с `npm run render:legacy`.
